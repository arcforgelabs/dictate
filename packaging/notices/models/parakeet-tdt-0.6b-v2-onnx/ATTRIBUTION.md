# Parakeet TDT 0.6B v2 — attribution

This directory holds the speech model Dictate uses for dictation.

- **Model:** NVIDIA Parakeet TDT 0.6B v2 (`nvidia/parakeet-tdt-0.6b-v2`), by
  NVIDIA. <https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2>
- **This copy:** the ONNX conversion `istupakov/parakeet-tdt-0.6b-v2-onnx`,
  int8-quantised encoder and decoder.
  <https://huggingface.co/istupakov/parakeet-tdt-0.6b-v2-onnx>
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).
  <https://creativecommons.org/licenses/by/4.0/>
- **Changes:** converted from NeMo to ONNX and quantised to int8 by the
  conversion's publisher. Dictate redistributes the files unmodified.
