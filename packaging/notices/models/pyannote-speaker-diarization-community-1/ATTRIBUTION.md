# pyannote speaker-diarization-community-1 — attribution

This directory holds the speaker-labelling pipeline Dictate uses for Meeting
mode (beta). `README.md` beside this file is the publisher's model card.

- **Model:** `pyannote/speaker-diarization-community-1`, by pyannoteAI and the
  pyannote.audio contributors.
  <https://huggingface.co/pyannote/speaker-diarization-community-1>
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).
  <https://creativecommons.org/licenses/by/4.0/>
- **Changes:** none. Dictate redistributes the published snapshot unmodified.
- **Built on:** Plaquet and Bredin, "Powerset multi-class cross entropy loss for
  neural speaker diarization" (INTERSPEECH 2023); Wang et al., "Wespeaker"
  (ICASSP 2023); Landini et al., "Bayesian HMM clustering of x-vector sequences
  (VBx) in speaker diarization" (Computer Speech & Language, 2022).
